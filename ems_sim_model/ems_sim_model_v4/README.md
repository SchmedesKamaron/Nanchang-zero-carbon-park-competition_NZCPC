# 南昌零碳园区 储能系统仿真数学模型 · v4

`ems_sim_model_v4` 依据《v3_Optimized_Version_审查意见.md》对 v3 优化版进行系统性修复，
并融合了另一份独立 v4 实现的干净 CLI / JSON 输出 / fail-loud 入参校验 / 短路滚动窗口等优点。
重点是**物理模型正确性、优化器约束、指标核算口径、对比实验公平性**，并补齐自动化回归测试。

## 一键使用

```bash
pip install -r requirements.txt        # 安装 numpy
python -m pytest -q                    # 运行 32 项回归测试
python run_simulation.py --params demo_params.json   # 四场景汇总报告(out/仿真结果报告.txt)
```

两种运行模式：
- **四场景汇总报告**：`python run_simulation.py [--params demo_params.json]`
- **单场景 JSON**（便于脚本/前端消费）：
  `python run_simulation.py --scene economic --seed 42 --out results.json`

## 修复要点（对照审查意见）

| 领域 | 审查问题 | v4 修复 |
| ---- | -------- | ------- |
| **P0 SOC 物理约束** | 放电按 `SOC×容量` 全量可用，忽略最低 SOC 预留，可放到负 SOC | 放电上限 = `(SOC-SOC_MIN)·E_cap·η_dis`，先限功率再更新 SOC，并断言在界内 |
| **P0 充放电公式** | 充电 SOC 更新与效率公式不一致 | `SOC+=P·dt·η_ch/E`（充）、`SOC-=P·dt/(E·η_dis)`（放），功率侧与电池侧统一 |
| **P0 停电场景** | 停电仍可从电网购电，应急边界未落实 | 孤岛 `p_grid≡0`，缺供电量逐时统计，储能只放不购 |
| **P0 滚动窗口** | 4h 窗口切片但环境仍按 24h，触发 IndexError | 可变时域子环境 + 窗口间 SOC 连续传递，24h 整日重仿真校验 |
| **P0 罚函数方向** | SOC 越限罚方向写反，无法惩罚越界 | 按实际越限幅度正向平方罚，并把 `soc_end` 纳入 |
| **P1 需求响应** | `curtail` 只存结果不改变负荷；信号二次生成 | `curtail` 真实作用于 `load_eff` 并参与功率平衡；信号基于同一负荷推导 |
| **P1 公平对比** | 基线与各重启用不同随机曲线 | 基线与所有 IPSO 重启共享同一 `state`，多重启按 fitness 择优 |
| **P1 碳排放** | 单位错误，少算 1000 倍 | MWh→kWh 后再乘 kg/kWh 排放因子 |
| **P1 经济核算** | 重复计利、充电成本按全部充电量计 | `f_econ = 基线购电 - 实际购电 - 运维 + 实际DR补贴`，光伏/电网充电分账 |
| **P1 目标量纲** | 经济(千元) vs 消纳/削峰(0-100)量纲失衡 | 三项归一化到 [-1,1]/[0,1] 再加权，报告分项归一化贡献 |
| **P2 场景缩放** | scenes 与 environment 重复缩放(0.55²、1.15) | 缩放唯一来源为 scenes.py |
| **P2 参数校验** | 非法参数静默通过 | `apply_params` 严格校验并显式报错；`step()` 入参 fail-loud（长度/非负/有限/SOC 界内） |
| **P2 测试** | 无自动化测试 | `tests/` 32 项回归测试全通过 |

## 物理约定（全项目统一）

- `p_batt > 0` 放电、`< 0` 充电；`p_grid > 0` 从电网购电（停电时为 0）
- 功率 MW，能量 MWh，电价 元/kWh，排放 kgCO2/kWh，时间步 `DT_HOURS=1.0`
- 每个时段四步：①需求响应削峰得 `load_eff` → ②光伏优先供负荷 → ③储能按 SOC/额定功率/余电定实际功率 → ④电网购电/弃光/SOC 更新
