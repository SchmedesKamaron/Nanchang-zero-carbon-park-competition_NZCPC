# ems_sim_model_v2 优化记录

本目录为"南昌零碳园区储能系统仿真数学模型"的优化版，面向 **前端填表 → 跑程序 → 给答复** 的交互流程重构。

## 使用流程
1. 打开 `前端填表.html` 填写各项参数
2. 点「生成配置」复制 JSON
3. 把 JSON 存为 `params.json`，运行：
   ```bash
   python run_simulation.py --params params.json
   ```
4. 输出见终端 / `out/仿真结果报告.txt`

## 优化器修复（本次核心改动）
原 `ems_sim/optimizer.py` 存在一个**方向性 bug**：决策变量约定「负=充电、正=放电」，
但粒子初始化却把谷段钳成放电(正)、峰段钳成充电(负)，导致 IPSO 从错误区域起步、
收敛到劣于启发式基线的解。

本次修复：
1. **方向 bug**：谷段 `min(x,-P*0.4)` 偏充电、峰段 `max(x,P*0.2)` 偏放电。
2. **惯性权重线性递减** 0.9→0.4，前期探索、后期收敛。
3. **多精英粒子注入**：前 6 个粒子以启发式基线为心加扰动，保证起点不劣于基线。
4. **需求响应削峰初始化**：该场景峰段强放电，使网格协同价值可被搜索到。
5. **多随机重启取最优**：主入口对每场景跑 3 组随机种子取最高 F，消除随机波动。
6. **经济账修正**：放电收益去掉重复计效率、年收益概算按日净收益×生产天数。

## 修复后效果（默认参数，IPSO vs 启发式基线）
| 场景 | 基线 F | IPSO | 结论 |
|---|---|---|---|
| 日常经济 | 3141.4 | 3157.5 | ✅ 优化优于基线 |
| 光伏消纳 | -136.6 | 888.2 | ✅ 大幅优化 |
| 需求响应 | 1677.5 | 1679.6 | ✅ 削峰有效 |
| 应急备用 | -13.1 | -3.7 | ✅ 负荷缺口减少 |

> 备注：需求响应年收益中的补贴按「削峰放电量×3元/kWh」估算可能偏高(见文章其值约18–25万/年)，
> 属模型估算参数，可视需要调低参与系数。
