# ems_sim_model_v4 — 审查修复变更摘要（融合版）

> 依据《v3_Optimized_Version_审查意见.md》生成，并融合另一份独立 v4 实现的
> 干净 CLI/JSON 输出、fail-loud 入参校验、短路滚动窗口等优点。
> 修复覆盖审查报告 P0/P1/P2 全部条目，并新增自动化回归测试。
> 所有结论均以"实际运行 + 测试"为准，不再依赖单次偶然结果。

## 一、物理模型（先修 P0）

- **SOC 不越界**：放电上限按可用能量 `(SOC-SOC_MIN)·E_cap·η_dis`，充电按剩余空间 `(SOC_MAX-SOC)·E_cap/η_ch`；
  先限功率再更新 SOC，并用断言兜底（不用 clip 掩盖电量不守恒）。
- **功率平衡逐时闭合**：`pv_use + p_grid + 放电 = load_eff + 充电`（非停电），弃光/缺供/购电均对账。
- **停电孤岛**：`p_grid ≡ 0`，缺供电量按光伏+储能实际可用能力统计；不再出现"停电仍购电"。
- **需求响应落地**：`curtail` 真实削减净负荷并参与功率平衡；DR 信号基于同一负荷曲线推导一次。
- **场景缩放去重**：缩放唯一来源为 `scenes.py`，删除 environment 内二次 `×0.55 / ×1.15`。

## 二、指标核算（修 P0/P1）

- **碳排放单位**：`MWh → kWh` 后再乘 `kg/kWh`，消除 1000 倍量级错误。
- **经济统一边界**：`f_econ = 基线购电成本 - 实际购电成本 - 运维 + 实际DR补贴`，不重复计利；
  光伏充电与电网充电分账，充电成本不再高估。
- **DR 补贴按实际响应量**：只对 DR 场景申报时段、按实际执行功率核算，非把所有峰段放电都计为补贴。
- **目标量纲归一化**：经济(元)、消纳(0-1)、削峰(0-1)归一化后按权重加权，报告输出各分项归一化贡献。

## 三、优化器（修 P0/P1）

- **罚函数方向修正**：SOC 越限按实际幅度正向平方罚，纳入 `soc_end`；物理约束由 step 硬保证，罚函数仅引导。
- **最终策略独立验收**：返回前检查 SOC/功率/循环/停电购电，违规策略不进入报告主结果。
- **日内滚动调度**：可变时域子环境 + 窗口间 `SOC_start,k+1 = SOC_end,k` 连续传递，4/6/24h 窗口均可用。
- **公平对比**：基线与所有 IPSO 重启共享同一 `state`；多重启优先选可行解、再按 fitness 择优。

## 四、工程（修 P2）

- `apply_params` 严格参数校验：容量/功率>0、`SOC_MIN<SOC_MAX`、效率∈(0,1]、负工作天数/负补贴/空场景/非法权重一律显式报错。
- `environment.step()` fail-loud：长度不匹配、含负值/NaN、初始 SOC 越界等直接抛 `ValueError`，不静默计算。
- `run_simulation.py` 双模式：四场景汇总报告 + 单场景 JSON（含基线/优化约束检查、充放电计划、收敛曲线）。
- `tests/` 32 项回归测试全通过，覆盖审查报告第四节全部验收场景及短路滚动窗口、入参校验。

## 五、验证方式

1. `python -m pytest -q` → **32 passed**。
2. `python run_simulation.py --params demo_params.json` → 四场景均输出 **可行性验收：通过 ✓**，
   SOC 全程在 [20%,90%]，停电场景购电 0。
3. `python run_simulation.py --scene economic --seed 42 --out results.json` → 单场景 JSON 约束检查全过。
4. 关键回归点独立抽查：极端放电不跌破下限、恒定电价无套利、1 MWh 购电 ≈ 1000×排放因子、
   4/6/24h 及非 24 整数倍滚动窗口可运行且 SOC 连续、非法入参显式报错。
